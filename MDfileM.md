# First Monthsary Surprise Website 💖

## Project Overview

Create a romantic interactive HTML/CSS/JavaScript website that will be opened by scanning a QR code.

The website serves as a surprise gift for my girlfriend on our **First Monthsary**.

The design should feel:

* Romantic
* Dreamy
* Nostalgic
* Interactive
* Personal

Inspired by retro Windows 95 / Y2K websites with floating windows, soft aesthetics, and smooth animations similar to the provided reference image.

---

# Opening Experience

## First Visit Popup

When the website loads:

Display a fullscreen overlay popup.

### Animation

* Fade-in effect
* Background blur
* Heart appears with scale-up animation
* Floating sparkles around the heart
* Soft romantic entrance transition

### Heart Content

Inside the heart:

**Happy First Monthsary, My Baby! ❤️**

Below the message:

**Tap the heart to continue**

### Interaction

The heart should:

* Gently pulse
* Slight glow effect
* Be clickable

When clicked:

* Heart expands
* Overlay fades away
* Smooth transition to the main website
* Optional soft romantic sound effect

---

# Main Website Experience

Reveal a retro desktop-style interface.
